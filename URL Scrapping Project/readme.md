# Coventry University URL Course Scraper

## Setup
1. Ensure Python 3.x is installed.
2. Install dependencies:
   `pip install requests beautifulsoup4`

## How to Run
Run the following command in the terminal:
`python3 test.py`

## Output
The script extracts 5 courses from the Coventry University homepage and saves them to `coventry_courses.json`.

** OBJECTIVES **
1. automated data extraction for Coventry University website
2. strictly based on the official website link and no other sources.
3. implemented using CSS class selectors.


** CHALLENGES **
1. url handling -> the website uses relative paths and not full length urls. 
                    so, i implemented URL joining logic.


** SCHEMA **
1. output -> JSON array of objects.
2. data consistency -> Every record has full set of keys defined in the Required Data Schema.
